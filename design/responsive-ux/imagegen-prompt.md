# Image generation prompt

Use case: ui-mockup

Asset type: responsive design reference board for a real engineering work-management web application

Primary request: Create one polished multi-viewport UI design sheet showing the same dark-mode Work board at four widths: mobile phone 390px, compact laptop 1024px, desktop 1366px, and wide desktop 1600px. The design must demonstrate thoughtful responsive changes, not simple scaling.

Product context: VertexADE is a dense engineering workspace for work items, pull requests, agent threads, reviews, and deployments.

Style/medium: high-fidelity product UI mockup, crisp dark navy interface, restrained blue/violet/emerald/amber accents, Geist-like typography, subtle borders and shadows, professional developer-tool aesthetic.

Composition/framing: four clearly separated viewport frames on one neutral presentation canvas, shown from narrow to wide. Mobile uses a bottom action dock and one selected workflow column. 1024px uses a compact icon rail and a two-column work layout. 1366px uses a compact icon rail and a readable five-column board. 1600px uses an expanded navigation sidebar and five spacious columns. Keep toolbar controls grouped and avoid excessive nested cards.

Required hierarchy: app header, concise Work title row, compact summary metrics, search and filter toolbar, workflow columns labeled Backlog, Active, Review, Deploy, Done, and representative work cards with clear title, status signal, repository/activity metadata, and one dominant next action.

Text where visible: Work, Backlog, Active, Review, Deploy, Done, New work.

Constraints: prioritize readable card widths and information density; show intentional breakpoint-specific navigation; align gutters and vertical rhythm consistently; retain touch-friendly controls on mobile; no decorative marketing hero.

Avoid: generic analytics dashboard, giant empty whitespace, tiny unreadable text, glassmorphism, excessive gradients, duplicated page headers, horizontal page overflow, watermark.
